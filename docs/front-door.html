Prototype

Meadowvale Borough Council is fictional. Nothing you enter is sent or stored.

The catalogue is the asset; the interface is disposable. One data file — services.json — drives the search below, and could drive an assistant, a voice agent or a third party model later. The panel on the right shows the raw data behind whatever you see.

No AI is used here. Matching is plain keyword and alias lookup running in your browser — open services.json to see the data for yourself. Nothing you type leaves this page; there is no backend, database or stored history.
