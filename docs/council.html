What happens when you call

An officer takes a few details, checks whether we have a duty to house you tonight, and arranges emergency accommodation if you need it. Bring ID if you have it — but don’t worry if you don’t.

If you’re in immediate danger, call 999. This is a prototype; the number is fictional.
